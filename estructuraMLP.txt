Metodología del entrenamiento
1. Definir una única métrica que servirá para evaluar el modelo
 (Comparación con modelos y selección de “buenos” hiper-parámetros)

2. Entender que es lo que espero de mi modelo
 (Que sería un buen resultado para esa métrica: Baselines con modelos 
sencillos y topes mirando resultados de humanos o 
error de bayes)

3. Entrenar modelo y mirar el Train set para ver si hay alto bias
 (¿Que tal lejos estoy de lo que supuse en el punto 2?)
 
4. Si tenemos alto bias => Agrandar Red (Aumentar cantidad de 
parámetros del modelo), Entrenar más tiempo. (Distinguir 
esto de que el modelo no aprende, por ejemplo learning 
rate demasiado grande o demasiado chico)

5. Una vez que se logró un bias aceptable 
mirar performance de CV o dev para ver si hay alta Varianza

6. Si alta varianza => ¿Conseguir más datos, A
chicar red, Early stop, regularización? Por esto dividimos el DS en 3

7. Puede volver al paso 3 y sacrificar algo de bias para ganar generalización. 

8. Evaluar en Test Set


Recomendaciones: no cambiar varios hiper-parámetros al mismo tiempo. Usar algún tipo de técnica de grid search 
(sklearn) o optimización bayesiana (hyperopt)

La busqueda de hiperparametros se realizara con TPE pruning de OPTUNA, utilizando 100

Se hace busqueda con softmax para compararcon tp anterior.


Media de pesos:  Se medira la media de abs(w_i)

En una primera iteración se encontró una configuración que presentó la mayor 
OFM observada (dentro de esa iteración): 47,27 puntos porcentuales, en la época 
4 de un entrenamiento de 5 épocas. En esa época, la accuracy fue 95,92 % en 
train y 48,65 % en validación. Esta diferencia muestra un ajuste considerablemente 
mayor sobre los datos de entrenamiento que sobre los de validación.

El modelo tenía dos capas ocultas de 64 y 256 neuronas, ambas con activación Tanh. 
Se utilizó SGD sin momentum, con learning rate 0,0156964, batch size 32 y 
semilla 42. El preprocesamiento conservó las stopwords y no aplicó stemming ni 
lematización. La representación TF-IDF incluyó unigramas y bigramas, 
un máximo de 10.000 features y min_df = 2. Posteriormente se aplicó 
normalización mediante StandardScaler, ajustado exclusivamente con train.

Al finalizar la quinta época, la accuracy alcanzó 96,80 % en train y 50,24 % en 
validación, con una OFM de 46,55 puntos porcentuales. Por tanto, la mayor 
OFM registrada corresponde a la cuarta época, no a la última.
